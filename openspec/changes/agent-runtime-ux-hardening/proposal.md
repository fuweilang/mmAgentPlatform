# agent-runtime-ux-hardening

本地进行中的交接 change。记录 2026-10 对话窗口里已改的 Octop/中台胶水，方便下一窗口继续。

## 背景

产品主路径是浏览器里的 AI 对话 / 专家 / 自动化 / 模型配置。没有事先拆完任务，边用边改。需要一份短文档记住改了啥、刻意没做啥。

## 目标

- 对话过程少露英文推理；发出去的用户话立刻出现在右侧。
- 过期专家 URL 不再 404 刷屏。
- 品牌空状态/欢迎吉祥物能显示；内置专家卡片图标不发黑。
- 侧栏能进「管理」；中台平台超管 SSO 后在 Octop 是管理员。
- 下一窗口能从 `tasks.md` 未勾项接着干。

## 范围

- Octop dashboard：`Octop/dashboard/`
- 中台 OIDC：`apps/backend/src/oidc/oidc.service.ts`
- 网关静态前缀相关（`/agent/`）

## 非目标

- 侧栏「空间 / 文件夹」导航（明确以后再做）
- 回形针上传产品方案（只讨论过，未实现）
- 限制 Agent 工具回合数 / 改专家提示词降慢
- 语音识别在局域网 HTTP 下可用（已定位，未改）
- 自动化页改动
- 提交/推送 git
- 把 Octop「管理 / 控制」开放给企业管理员或普通员工
- 法律 ERP（案件、计费、卷宗、开庭）
- 客户本机磁盘 / 遥控电脑

## 用户流程（当前）

1. `/login` 用 `13800000001` 登中台，OIDC 进 `/agent/chat`。
2. 选专家对话；执行中思考默认折叠；中途再发一句话应立刻靠右出现。
3. 内置专家从 `/agent/experts` 创建。
4. 管理员从侧栏「管理」进用户 / 模型 / 存储 / 插件 / 安全 / 应用设置。
5. 模型页加提供商后，对话输入框可换模型。

## 风险

- Octop 定制 diff 要小，方便 rebase 上游。
- 强制露出管理菜单，会盖过用户自定义导航里「隐藏管理」的选择。
- 平台超管升 Octop admin 后权限很大，只应对 `is_platform_admin=true`。

## 终端企业控制台

两套后台：`/agent` 管理/控制 = 平台超管；`/console/` = 终端企业。普通员工只聊天。

P0 已落地：智能体、知识库、本企业成员、工作台。「租户」只给超管。法律种子 = 法律顾问人设 + 分库目录。知识库已接入对话检索。

P1 已落地：用量/配额、审计、企业设置。  
P2：技能开关、模板、渠道。

详见 `specs/enterprise-console/spec.md`。
